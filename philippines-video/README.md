# Philippines — 30s Portrait Motion Graphics

A vertical (1080x1920) 30-second motion-graphics sample video celebrating the
Philippines, rendered at 30 fps and encoded to H.264 MP4. Designed for Reels,
Stories, TikTok and other portrait placements.

## Files

| File | Purpose |
|------|---------|
| `index.html` | The animation source — a self-contained HTML5 Canvas scene renderer |
| `philippines_30s_portrait.mp4` | Final video (1080x1920, 30s, 30fps, H.264) |
| `poster.jpg` | Poster/thumbnail (frame at t=3.0s) |

## How to Re-render

`index.html` is the single source of truth — all scenes are drawn frame-by-frame
on a Canvas, driven by a global `window.renderFrame(t)` function (where `t` is the
time in seconds). The MP4 is generated by capturing each frame via headless
Chromium (Playwright) and encoding with ffmpeg:

1. Launch a headless browser at 1080x1920, load `index.html`, wait for
   `window.ready === true`.
2. For each of the 900 frames (30fps x 30s), call `renderFrame(i/30)` and save the
   canvas as a PNG (`frames/fNNNN.png`).
3. Encode:

   ```bash
   ffmpeg -y -framerate 30 -i frames/f%04d.png \
     -c:v libx264 -pix_fmt yuv420p -crf 19 -preset medium \
     -movflags +faststart philippines_30s_portrait.mp4
   ```

4. Poster: `ffmpeg -y -i frames/f0090.png -q:v 2 poster.jpg`

The generated `frames/` directory is intermediate and not committed.
